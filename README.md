# Pratik Tawhare | Full-Stack & DevOps Developer Portfolio

Welcome to my personal developer portfolio! This project showcases my skills, experience, and the various projects I've built. It is designed to be interactive, visually stunning, and highly performant.

## 🚀 Live Demo

[View Live Portfolio](https://pratik-tawhare.vercel.app/) *(Update this link after deploying to Vercel)*

## 🛠️ Technology Stack

This portfolio is built using modern web technologies to ensure a smooth, immersive user experience:

- **Frontend Framework:** React (v19)
- **Build Tool:** Vite
- **3D Graphics & Animations:** Three.js, React Three Fiber, React Three Drei
- **Motion & Interactions:** Framer Motion, GSAP
- **Styling:** Tailwind CSS (v4)
- **Deployment:** Vercel

## ⚙️ Local Development Setup

To run this project locally, simply follow these steps:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/pratiktawhare/Portfolio.git
   ```

2. **Navigate to the project directory:**
   ```bash
   cd Portfolio
   ```

3. **Install dependencies:**
   ```bash
   npm install
   ```

4. **Start the development server:**
   ```bash
   npm run dev
   ```

5. **Open your browser:**  
   Navigate to `http://localhost:5173` to view the portfolio.

## 📦 Deployment to Vercel

This project is configured for seamless deployment to [Vercel](https://vercel.com). The repository includes a `vercel.json` file configuring single-page application routing and optimal caching for assets.

1. Create a new project on Vercel and import this GitHub repository.
2. The framework preset should automatically be detected as **Vite**.
3. Vercel will automatically use `npm run build` and serve the `dist` directory.
4. Click **Deploy**!
